# 対面集計ドリルダウン実装計画

## 1. 抽出ロジック

- 集計軸と行名から元の対戦を抽出する純粋関数を追加する。
- 結果・先後フィルターを組み合わせる。
- パス値から表示用バッジを生成する。
- 正常系、未記録、複合フィルターをユニットテストする。

## 2. 対面詳細画面

- 分析のクロス集計行を専用画面へのボタンに変更する。
- 総合・先攻・後攻と結果フィルターを表示する。
- 条件に一致する対戦を二行カードで表示する。
- 編集後もルートとフィルターを維持する。

## 3. 共通カード展開

- 対戦カードとパスバッジのマークアップを共通化する。
- プレイヤー履歴へ適用する。
- セッション一覧へパスバッジを適用する。
- 管理者プレビューでは閲覧専用にする。

## 4. スマートフォン検証

- 320px、390px、430px幅で二行表示と省略順を確認する。
- 全テストを実行する。
- Service Workerのキャッシュ対象とバージョンを更新する。
- mainへ反映しGitHub Pagesの公開を確認する。
