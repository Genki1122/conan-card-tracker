# 管理者向けアカウント整理

## 目的

- 管理者画面の人数表記を、登録利用者と絞り込み対象利用者で区別する。
- 利用者一覧を最終同期の新しい順で開く。
- 同じユーザー名で重複登録された空アカウントを、安全に削除できるようにする。
- 管理者向け変更を利用者向け更新通知へ掲載しない。

## 削除条件

- 実行者が superadmin であること。
- 削除対象が実行者本人または管理者ではないこと。
- 残すアカウントと削除対象が別で、正規化したユーザー名が一致すること。
- 削除対象のデッキ、セッション、試合がすべて0件であること。
- 削除対象に処理中の引き継ぎ記録がないこと。
- 削除確認欄に対象のユーザー名が一致していること。

すべての条件は画面だけでなくSupabase側でも再検証する。削除時は対象、残すアカウント、実行者、件数を管理履歴へ保存する。

## UI

- 同名登録がある利用者には一覧で「同名登録」チップを表示する。
- 各利用者行の「管理」から、登録日、最終同期、保存件数、ID末尾を確認できる。
- 同名候補から残すアカウントを選び、削除対象のユーザー名を入力して確定する。
- データがあるアカウントは削除ボタンを表示せず、将来のデータ統合対象として案内する。

## 公開

利用者向け `appVersion`、`releases.json`、Service Workerのバージョンは変更しない。管理者向けの画面とデータベース処理だけを更新する。
